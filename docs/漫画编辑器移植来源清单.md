## 4. 未移植的上游部分（有意排除）

- `ComicAIStudio.js`、`ComicAIStudio.test.mjs`、`ComicAIStudio.ai.test.mjs`、`ComicAIStudio` 相关 `comicAI.mjs`：
  上游自己的 NovelAI 漫画生成流程。本项目已有一键编排、供应商与预设，不重复引入。
- `ComicLLMSettings.js`、`ComicAIPlanEditor.js`：上游 LLM 配置界面，同上。
- `comicStorage.mjs`（IndexedDB 页面库）、`comicProject.mjs`（ZIP 项目包）：
  本项目的正式存档在服务端（`editor_doc`），浏览器只做草稿缓存，避免换浏览器后“数据像丢了”。
- `ComicElementDialog.js`、`ComicCropDialog.js`、`ComicLayerPanel.js`：
  交互已按本项目样式重写，未复制其 MUI 实现。
- 上游模板库 `COMIC_TEMPLATES`：**明确不使用**，见第 2 节。
