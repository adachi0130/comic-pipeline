## 一、这是什么：定位与设计目标

一句话：**你只写故事大纲，系统按"六个阶段"把大纲变成一本漫画**，每个阶段之间可以停下来人工审核，也可以切成全自动一口气跑完。

设计目标（也就是它想解决的问题）：

| 目标 | 具体做法 |
|---|---|
| **不让 AI 一口气瞎编** | 拆成 6 个阶段，每阶段只做一件小事，产物可单独检查、单独重跑 |
| **写作用你自己的酒馆人设** | 正文交给 SillyTavern 生成，完整走角色卡 / 世界书 / 预设 / Prompt Manager |
| **出图接你已有的 ComfyUI 工作流** | 不重造轮子，只注入参数（提示词/尺寸/LoRA/采样），换工作流不改代码 |
| **拼页排版用成熟开源工具** | 分页合成用 Manga Editor Desu（69 个漫画版式模板） |
| **改一处不用全部重来** | 产物版本化 + 血缘，改上游自动把下游标"需重跑"，只重跑受影响的部分 |
| **既能无人值守也能人工精修** | 一个「全自动 / 人工审查」总开关 |

**它不是什么**：不是一键出成品商业漫画的工具。它是**草稿级全自动、精修靠人工**的生产线；画面一致性和出版级质量受限于你用的绘图模型。

## 二、功能总览

按界面菜单组织（前端 http://127.0.0.1:8770/ui/ 的左侧导航）：

| 菜单 | 对应阶段 | 能做什么 |
|---|---|---|
| **项目** | — | 新建/切换漫画项目；设标题、目标页数、故事大纲；切「全自动 / 人工审查」 |
| **正文** | S1 | 三种写作方式（酒馆写 / 调 LLM 写 / 自己粘贴）；逐段审核（通过/驳回/编辑/删除）；导出全文 TXT |
| **流水线** | 全局 | 看各阶段进度与审查门；运行某阶段；看作业进度、随时取消 |
| **分格分页** | S2 | 每页选版式模板（或让 AI 选）；打分格脚本（动作/表情/台词/场景/出场角色）；改版式；预览/编辑正文产物 |
| **提示词** | S3 | 每格生成一句出图提示词（正/负向 + LoRA + 尺寸）；绑角色触发词与角色 LoRA；正负向预设；项目画风 LoRA；逐格预览/编辑/通过 |
| **出图** | S4 | 连 ComfyUI、选工作流、看/改参数；逐格出图（每格多张）；挑图/上传/下载/删除候选图 |
| **分页合成** | S5 | 把选好的画面按漫画框拼成整页；一键去 MED 精修；换同格数版式 |
| **设置** | — | 配 LLM 供应商（可一键从酒馆导入）；配 ComfyUI；把各阶段绑定到不同供应商 |

> ⚠️ **注意**：目前**没有独立的「导出」菜单**。整册导出（S6，PDF/CBZ）在后端已实现，
> 从「**流水线**」页的 S6 卡片点「运行」触发。前端现有的导出入口为：正文页的「导出 TXT」、
> MED 工作台的「导出 PNG」。

## 三、运行需求

### 3.1 必需

| 需求 | 说明 |
|---|---|
| **Python 3.11–3.13** | 后端与脚本 |
| **Git** | 拉取代码 |
| **Manga Editor Desu** | 分页合成用，约 99MB，用 `fetch_editor.*` 脚本按锁定版本拉取（不随仓库分发） |
| **Node.js 18+** | 只在**生成版式模板菜单**时用一次（脚本内部调 `node`） |

### 3.2 按需（想用对应功能才需要）

| 需求 | 用来做什么 | 不装会怎样 |
|---|---|---|
| **LLM 供应商**（任意 OpenAI 兼容端点：DeepSeek/Kimi/智谱/DashScope/OpenRouter/Ollama…） | S2 分页分格、S3 分镜提示词 | 这两个阶段跑不了（其余可用） |
| **ComfyUI**（本机或云端） | S4 逐格出图 | 出不了图 |
| **SillyTavern 酒馆** 1.13.x | S1 正文生成 | 正文只能手写/另想办法 |

### 3.3 安装三步（详细见 README）

1. 建虚拟环境装依赖 + `playwright install chromium`；
2. `fetch_editor.*` 拉取 MED；
3. `build_template_menu.py` 生成版式菜单 + `seed_techniques.py` 灌技法库。

## 四、漫画创作流程（核心）

这是全书的骨架：**六个阶段，中间五道审查门**。

```
S1 正文   →  G1  →  S2 分页分格  →  G2  →  S3 分镜提示词  →  G3  →  S4 逐格出图  →  G5  →  S5 分页合成  →  G6  →  S6 整册导出
(酒馆写小说)      (选版式+分格)        (每格一句出图词)        (ComfyUI 出图)       (MED 拼页)          (PDF/CBZ)
```

> 注：代码里的阶段编号是 **S1 正文 / S2 分页分格 / S3 分镜提示词 / S4 逐格出图 / S5 分页合成 / S6 整册导出**。
> 早期方案里的"S1 结构规划"已取消，不在这条流程里。

### 4.1 各阶段：谁做、输入、输出、在哪操作、怎么过门

| 阶段 | 谁来干 | 输入 | 输出产物 | 在哪个菜单操作 | 进下一阶段的条件（硬门） |
|---|---|---|---|---|---|
| **S1 正文** | **酒馆**（你选的角色卡/世界书/预设） | 你的提示词/大纲；上一段正文 | 一段段正文（每段一个产物 `seg:N`） | 「正文」页 → 开始写作 / 续写 | 至少 **1 段正文被通过** |
| **S2 分页分格** | **LLM** | 已通过的正文 + 目标页数 + 69 模板菜单 + 技法库 | 每页一个分格脚本 `page:N`（版式 + 每格动作/台词/场景/角色） | 「分格」页（可让 AI 选版式，或自己选） | 至少 **1 页分格脚本被通过** |
| **S3 分镜提示词** | **LLM** | 已通过的分格脚本 + 角色资产 + 预设 + LoRA 配置 | 每格一个提示词 `panel:N.M`（正/负向 + LoRA + 宽高 + 参数） | 「提示词」页 | 至少 **1 格提示词被通过** |
| **S4 逐格出图** | **ComfyUI** | 该格的 S3 提示词（词、尺寸、LoRA、参数） | 每格一批候选图 `IMAGE` | 「出图」页（挑图/上传） | 至少 **1 格有选定的图** |
| **S5 分页合成** | **MED 桥**（无头浏览器驱动） | 该页版式 + 每格选定的图 + 提示词 | 每页一张整页图 `PAGE_IMAGE` | 「分页合成」页（或直接去 MED 精修） | 至少 **1 页整页图被通过** |
| **S6 整册导出** | **后端**（img2pdf / zipfile） | 各页整页图 | PDF / CBZ / 两者 | 「流水线」页跑 S6 | —（终点） |

### 4.2 两种跑法

- **人工审查（默认）**：每个阶段产出后状态是"待审"，你在界面上看过、改过、**点通过**，才有资格进下一阶段。
- **全自动**：把总开关切到「全自动」，所有产物**一生成即视为通过**（出图自动取每格第一张）。可无人值守跑完整条链。

> 切开关的位置：界面右上角的「全自动」开关，或项目详情里切（对应 `PATCH /projects/{id}/review-mode`）。
> 后端脚本 `backend/scripts/autodrive.py --project 1` 可完全绕开前端跑完整条链。

### 4.3 一个真实的创作顺序（建议）

1. **想故事**：写一句/一段大纲（创建项目时填，或项目详情里改）。
2. **写正文（S1）**：进「正文」页，**先选一种方式**（酒馆写 / 调 LLM 写 / 自己粘贴）。以酒馆为例：填写作提示，点**开始写作**；酒馆写一段 → 你审核 → 满意就点**通过** → 点**续写**接着写下一段（**必须前面的段都通过才能续写**）。调 LLM 写会自动带上标题+大纲；粘贴则直接贴入。
3. **分页分格（S2）**：正文够了就去「分格分页」页，点某页的**让 AI 选**（自动选版式并分格），或**＋加一页**自己挑版式。逐页过一遍，可改台词/动作/出场角色，改完**保存分格**、**通过**。顶部可展开**正文产物预览**并就地编辑。
4. **设角色与画风（S3 前置）**：进「提示词」页，先把**角色卡**（角色名、触发词、角色 LoRA、外观词块）和**正/负向预设**、**项目画风 LoRA** 配好——这些会被每格提示词自动带上。
5. **生成提示词（S3）**：在「提示词」页点**整册生成**（或逐页**生成这页**、某格**准备**）。每格看**预览**确认正/负向、LoRA、尺寸，不满意**改**或用**改这格**手改，最后**一键全部通过**。
6. **出图（S4）**：进「出图」页，先**出图设置**里连 ComfyUI、选工作流（可**试跑一张**确认）。然后逐格**自动填写**（把你审好的提示词和 LoRA 填进来，不重新问 AI）→ 设**每格批量张数** → **出图**。出完在**候选图库**里挑，点中意的**采用**，或**上传**自己画的图。
7. **拼页（S5）**：进「分页合成」页，左侧选一页，右边核对画面与漫画框（阅读顺序已按**从右到左**），可**更换模板**（只列同样格数的版式）。点**去 MED 合成**自动摆好图与格框，在 MED 里精修（加气泡、网点、集中线），点**保存到「编辑中的页」**会自动跳回本页。
8. **导出（S6）**：去「流水线」页，在 S6 卡片点**运行**，产物得到 PDF / CBZ。

## 五、详细操作指南（按界面菜单）

### 5.1 项目

- **新建项目**：点「＋ 新建项目」，填**标题**、**目标页数**（默认 16）、**故事大纲**，创建后自动进入详情。
- **项目详情**：可改标题 / 目标页数 / 故事大纲（改完点对应「保存」）。
- **全自动开关**：右上角，开后所有审查门自动通过。
- **去「正文」页编辑**：快捷跳转。

### 5.2 正文（S1）

先选**一种写作方式**，下方才显示对应操作区（选了会记住）：

1. **① 用酒馆写**：没有自动拼词的入口；而是**在下方「酒馆对话」里直接发一条**给酒馆（相当于你在酒馆聊天框里发话）——**只把这次新返回的内容**存为正文，历史消息不写入产物。
   - 走完整角色卡/世界书/预设管线；可用「对话列表」切换当前会话。
   - 输入框旁有「**引用故事大纲**」按钮：点一下把项目详情里的故事大纲复制进输入框（追加，不覆盖已有内容）。
2. **② 调用 LLM 写**：用「设置」里配置的 LLM 供应商写作，**项目标题与故事大纲会自动发送给 LLM**，不经过酒馆。
   - 输入框是**额外需求 / 续写要求**（可留空）；同样有**开始写作 / 续写**；需先在「设置」配好供应商。
   - 右上角「**提示词模板**」可编辑发给 LLM 的系统提示词与用户模板（占位 `{{TITLE}}` / `{{OUTLINE}}` / `{{INSTRUCTION}}` / `{{CONTEXT_TAIL}}`）。
3. **③ 自己粘贴**：把已写好的正文粘进文本框，点**追加为正文**。

三种方式产出的正文完全等价，都会进入底部：

- **分段审核**：每段可**编辑 / 通过 / 驳回 / 删除**。「驳回」只做标记，不会自动改写。
- **小说全文**：**刷新 / 复制全文 / 导出 TXT / 清空全部正文**（只统计已通过的分段）。

### 5.3 流水线

- **阶段卡片 S1–S6**：显示每阶段产物数量与状态（N 项 / 通过 / 待审 / 需重跑），点**查看**看产物，点**运行**跑该阶段。
- **作业进度**：实时显示（SSE）。每个作业右侧有 **✕**，可随时**取消**（取消会真的中断 ComfyUI 生成）。

### 5.4 分格分页（S2）

- **正文产物预览（可编辑）**：可折叠卡片，展示作为分格依据的正文（只含已通过分段），每段可**编辑**（改完生成新版本，下游分格标「需重跑」）。
- **＋ 加一页（选版式）**：弹出 69 个版式缩略图（竖版/横版分组），选一个。
- 每页卡片：**通过 / 驳回 / 让 AI 选 / 编辑·换模板 / 删除**。
- **编辑**页内可改每格的**动作/表情、台词、场景、出场角色**，可**换个版式**、**按此页重跑提示词**、**保存分格**。

### 5.5 提示词（S3）

这是全项目最"重"的一页，分三块：

1. **角色触发词 与 提示词预设**（可折叠）
   - **角色卡**：角色名、**触发词**、**用 LoRA** 勾选、**角色 LoRA 文件名**（输入即搜）、权重、**外观词块**。触发词与角色 LoRA 绑定；LoRA 可留空（那就只用提示词描述外观）。
   - **正向预设 / 负向预设**：作为正/负向的**基础词**喂给 AI；可绑 LoRA、可勾「默认」、可设「本项目/全局」。改动**自动保存**。
   - **拉取后端 LoRA 列表**：从 ComfyUI 拉 LoRA，供上面的下拉搜索用。
2. **项目画风 LoRA**（可折叠）：**每次生成都带上**的画风 LoRA，单独**保存**。
3. **逐页逐格**：每页有**预览整页**、**生成这页**；每格有**预览 / 改 / 通过 / 驳回**。
   - **预览**看这一格完整的正向/负向/LoRA/尺寸/画框；**改**可调宽高、seed、steps/CFG/sampler/scheduler/denoise、正负向、LoRA 行。
   - 顶部有**刷新 / 整册生成 / 一键全部通过 / 提示词模板**（可改系统与用户提示词，支持**还原默认**）。

### 5.6 出图（S4）

- **出图设置**（弹窗）三步：① **连接**（选本机/云端 + 地址 + Key）→ 拉回工作流与 LoRA 列表；② **点一个工作流看参数**（自动解析文本参数、LoRA 槽、采样参数）；③ **就用它出图** / **试跑一张**。
- **分格产物**（可折叠）：每页/每格的详情，每格可**准备**（同步生成该格提示词）。
- **候选图库**（可折叠）：按格分组，点图可**采用**，可**上传**，可**下载 / 删**。
- **逐格出图**（可折叠）：每格设**张数**，**自动填写**（把已审好的提示词 + 角色/画风 LoRA 填进来，**不重新请求 AI**），**出图**。展开后是**详细信息**（正/负向、LoRA 行，改动自动保存）。
- **候选图与审查**：下拉切换看某类产物（候选图 S4 / 分页分格 S2 / 提示词 S3 / 整页成图 S5 / 正文分段 S1），可**通过 / 驳回**。

### 5.7 分页合成（S5）

- **合成全部就绪页**：把所有"每格都有图"的页批量合成。
- **左侧菜单**：每页显示 `已选/总格` 数，点开看右侧。
- **右侧预览**：漫画框 + 已选画面按**从右到左阅读顺序**叠加；显示模板与格数。
  - **更换模板**：只列**与当前格数相同**的版式。
  - **去 MED 合成**：自动装模板、摆图、落提示词，跳转 MED 精修。
  - **在 MED 打开**：空白 MED 打开（不自动摆图）。
  - **后台合成**：无界面合成，产物落盘。
- **已完成 / 编辑中的页**（可折叠）：显示已合成整页图，或"编辑中（MED 画布）"的预览，可**继续编辑**。

### 5.8 设置

- **LLM 供应商**：填名称/base_url/模型/api_key 添加；**从酒馆导入**一键复用酒馆的模型；可**测试**连通。
- **ComfyUI / 仙宫云**：选后端、**拉取资产（LoRA/ckpt）**、**打开出图设置**。
- **阶段 → 供应商绑定**：让 S2、S3 用不同供应商。

## 六、关键概念

| 概念 | 白话解释 |
|---|---|
| **产物（artifact）** | 每个阶段的输出都存成一条带版本的记录，永不覆盖，旧版可回退 |
| **ref** | 产物的定位键：正文 `seg:N`、页 `page:N`、格 `panel:N.M`、整页 `page:N` |
| **血缘（lineage）** | 记录"谁由谁产生"。改了上游，系统沿血缘把下游标 **stale（需重跑）** |
| **stale** | "过期/需重跑"，在「流水线」页和各阶段能看到 |
| **审查门** | 阶段之间的关卡。人工模式下产物停在"待审"，**通过**才放行 |
| **全自动 / 人工审查** | 总开关。自动=产物即通过；人工=到门停住等你 |
| **只重跑一格** | S3 支持"只给某一格生成提示词"（`panel_ref`），不用整页/整册重跑 |
| **LoRA 三级** | 合并顺序：**预设 → 项目画风 → 出场角色 → 模型给的角色**（后者覆盖权重） |
| **尺寸从画框来** | 每格出图宽高按**该格漫画框的形状**算（长边 1216、64 对齐），与排版一致 |
| **触发词** | 唤醒某个角色/画风 LoRA 的关键词，与对应 LoRA 绑定 |

## 七、常见问题

| 问题 | 原因 / 解决 |
|---|---|
| S3 生成后提示词里没有技法 | 没跑 `seed_techniques.py` |
| 「分格分页」页没有任何版式可选 | 没跑 `build_template_menu.py`（需要 node 和已拉取的 MED） |
| 「出图」连不上 ComfyUI | ComfyUI 没启动 / 地址端口不对 / 云端要 Key 或隧道 |
| 出图报"缺节点" | 工作流用了你 ComfyUI 没装的节点；在工作流体检里能看到缺哪些 |
| 「续写」按钮是灰的 | 前面的正文段还没全部"通过" |
| 点「去 MED 合成」打不开或按钮是旧的 | 关掉旧标签页重进；该入口带防缓存参数 |
| MED 里改了怎么保存 | 点「保存到『编辑中的页』」，成功后会自动跳回"分页合成"页 |
| 换工作流后参数没生效 | 需要重跑一次"自动映射"（参数映射表是每个工作流一份） |
| 想看整册 PDF/CBZ 从哪出 | 「流水线」页跑 S6；或用 `autodrive.py` |
