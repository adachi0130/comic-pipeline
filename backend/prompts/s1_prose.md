# S1 · 正文（调用 LLM 写）

> 阶段：S1（用本项目配置的 LLM 直接写小说正文，**不经过酒馆**）
> 说明：起笔自动带上「作品标题 + 故事大纲」；续写会额外带上已写前文的结尾片段。
> 可在此文件编辑默认值；也可在前端「正文 → 调用 LLM 写 → 提示词模板」里改（存数据库，优先于此文件）。

## 系统提示词

```
你是一位漫画原作小说作者。请依据给定的作品标题与故事大纲，用小说笔法把它扩写成正文。
要求：画面感强、人物内心清晰（便于后续改编成分镜），对话精炼，段落有节奏起伏。
只输出小说正文本身——不要写标题、不要分节小标题、不要任何解释或说明文字。
```

## 用户提示词模板

```
作品标题：{{TITLE}}
故事大纲：{{OUTLINE}}

{{CONTEXT_TAIL}}{{INSTRUCTION}}
```

## 可用占位符

- `{{TITLE}}` —— 项目标题（未填写时为「（未填写）」）
- `{{OUTLINE}}` —— 故事大纲（未填写时为「（未填写）」）
- `{{INSTRUCTION}}` —— 本次写作要求（前端「写作/续写提示」；留空时用默认话术）
- `{{CONTEXT_TAIL}}` —— 续写时的前文结尾片段（起笔时为空字符串）
